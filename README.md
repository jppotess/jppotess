# John Potess

I build products around AI, developer tools, and coding-agent
workflows.

I spent about a decade in frontend and product engineering before leaving my
Lead Frontend Engineer role to work full time on my own products.

I write essentially none of the implementation code now. Coding agents do
that.

My work has moved toward deciding what should exist, writing and refining
specifications, connecting the right context, evaluating the work, breaking the
product, measuring the result, and deciding what ships.

## Building

### [ShipFoundry](https://shipfoundry.ai/)

Product intelligence for agentic builders.

ShipFoundry tracks changes across the tools behind a product, checks what
matters against the product and codebase, and turns useful changes into
evidence-backed work for coding agents.

### [DiveJourney](https://divejourney.io/)

A global platform for scuba, freediving, and snorkeling with more than 12,000
dive spots and 234 destination guides.

DiveJourney is also my largest proving ground for building and operating a
production product almost entirely through coding agents.

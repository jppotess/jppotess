## Building

Product intelligence for agentic builders.

ShipFoundry tracks changes across the tools behind a product, checks what
matters against the product and codebase, and turns useful changes into
evidence-backed work for coding agents.

DiveJourney is also my largest proving ground for building and operating a
production product almost entirely through coding agents.
